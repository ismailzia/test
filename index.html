Download blocked? Right‑click the code (or long‑press on a phone) and choose “Save image”.

Print rule of thumb: make the code at least one‑tenth of the scanning distance. A table card read from 30 cm needs 3 cm; a poster read from 2 m needs 20 cm.

How much of the code can be scratched, folded or covered and still scan. Higher means more dots, so print it a little bigger.
